# 2DPhysSim
2D Powder/Physics simulation sandbox based on Pyglet

## The goal
Add more physics! I would like to make this just a fun thingy that people can use and enjoy, and create whatever with. Whether you just like powder physics, chemistry, or pure chaos and destruction, I aim to make this have just interesting stuff

## System requirements
A decent CPU is definitely recommended. Many calculations have to be performed as the canvas area is quite large, and a slow processor means that you can't place as much stuff without lag.

Because of the way pixels are currently rendered, it's pretty inefficient! Hopefully I can improve on this soon, but for now a good GPU is recommended as well

## Software requirements
Python: Python 3.10 or later (match-case is used, which isn't supported on older versions)

Libraries: pyglet
